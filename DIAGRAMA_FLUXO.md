## 🔍 DETALHAMENTO DAS FASES

### FASE 1: EXPORTAÇÃO

```
┌─────────────────────────────────────────────────────────────────┐
│                    EXPORT_MAP.PY                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  INPUT:                                                         │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ • world.otbm (binário OTBM)                              │  │
│  │ • items.xml (definições de itens)                        │  │
│  │ • monsters/*.xml (spawns)                                │  │
│  │ • npcs/*.xml (NPCs)                                      │  │
│  └──────────────────────────────────────────────────────────┘  │
│                                                                 │
│  PROCESSAMENTO:                                                 │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ 1. ItemsLoader                                           │  │
│  │    └─ Parse items.xml                                    │  │
│  │    └─ Classify items (floor/wall/door/object)           │  │
│  │                                                          │  │
│  │ 2. OTBMParser                                            │  │
│  │    └─ Read binary file                                   │  │
│  │    └─ Unescape control characters (0xFD)                │  │
│  │    └─ Parse node tree recursively                       │  │
│  │    └─ Extract tile coordinates (x, y, z)                │  │
│  │    └─ Extract item IDs                                   │  │
│  │                                                          │  │
│  │ 3. SpawnParser                                           │  │
│  │    └─ Parse monster XMLs                                 │  │
│  │    └─ Extract spawn positions                            │  │
│  │                                                          │  │
│  │ 4. NPCParser                                             │  │
│  │    └─ Parse NPC XMLs                                     │  │
│  │    └─ Extract NPC positions                              │  │
│  └──────────────────────────────────────────────────────────┘  │
│                                                                 │
│  OUTPUT:                                                        │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ • tiles.json                                             │  │
│  │   [{"x": 1024, "y": 1024, "z": 7, "t": "floor", ...}]   │  │
│  │                                                          │  │
│  │ • spawns.json                                            │  │
│  │   [{"name": "Dragon", "x": 1050, "y": 1050, ...}]       │  │
│  │                                                          │  │
│  │ • npcs.json                                              │  │
│  │   [{"name": "Rashid", "x": 1025, "y": 1025, ...}]       │  │
│  └──────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
```

### FASE 2: GERAÇÃO NO ROBLOX

```
┌─────────────────────────────────────────────────────────────────┐
│                   WORLDGENERATOR.LUA                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  INPUT:                                                         │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ • tiles.json (via HttpService)                           │  │
│  │ • spawns.json (via HttpService)                          │  │
│  │ • npcs.json (via HttpService)                            │  │
│  └──────────────────────────────────────────────────────────┘  │
│                                                                 │
│  PROCESSAMENTO:                                                 │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ 1. JSONLoader.loadFromURL()                              │  │
│  │    └─ HttpService:GetAsync(url)                          │  │
│  │    └─ HttpService:JSONDecode(data)                       │  │
│  │                                                          │  │
│  │ 2. TileMapper.otToRoblox()                               │  │
│  │    └─ Convert coordinates (x,y,z) → (X,Y,Z)             │  │
│  │    └─ Scale by TILE_SIZE (4 studs)                      │  │
│  │                                                          │  │
│  │ 3. TileMapper.createTilePart()                           │  │
│  │    └─ Create Part                                        │  │
│  │    └─ Set size (4x4 studs)                              │  │
│  │    └─ Set position                                       │  │
│  │    └─ Set material (Grass/Brick/Wood)                   │  │
│  │    └─ Set color                                          │  │
│  │    └─ Set collision                                      │  │
│  │                                                          │  │
│  │ 4. createSpawnMarker()                                   │  │
│  │    └─ Create red neon Part                              │  │
│  │    └─ Add BillboardGui label                            │  │
│  │                                                          │  │
│  │ 5. createNPCMarker()                                     │  │
│  │    └─ Create green neon Part                            │  │
│  │    └─ Add BillboardGui label                            │  │
│  └──────────────────────────────────────────────────────────┘  │
│                                                                 │
│  OUTPUT:                                                        │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ Workspace > OTWorld (Folder)                             │  │
│  │   ├─ Tile_floor_1024_1024_7 (Part)                      │  │
│  │   ├─ Tile_wall_1025_1024_7 (Part)                       │  │
│  │   ├─ Spawn_Dragon (Part + BillboardGui)                 │  │
│  │   └─ NPC_Rashid (Part + BillboardGui)                   │  │
│  └──────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
```

## 🎯 CONVERSÃO DE COORDENADAS

```
┌─────────────────────────────────────────────────────────────────┐
│              OTSERVER → ROBLOX COORDINATE MAPPING               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  OTSERVER (Grid 2D + Z-levels):                                 │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │                                                          │  │
│  │   Y (North/South)                                        │  │
│  │   ↑                                                      │  │
│  │   │                                                      │  │
│  │   │    ┌───┬───┬───┐                                    │  │
│  │   │    │   │   │   │  Z = 7 (andar)                     │  │
│  │   │    ├───┼───┼───┤                                    │  │
│  │   │    │   │ P │   │  P = (1024, 1024, 7)               │  │
│  │   │    ├───┼───┼───┤                                    │  │
│  │   │    │   │   │   │                                    │  │
│  │   │    └───┴───┴───┘                                    │  │
│  │   │                                                      │  │
│  │   └────────────────────→ X (East/West)                  │  │
│  │                                                          │  │
│  └──────────────────────────────────────────────────────────┘  │
│                                                                 │
│                          ↓ CONVERSÃO ↓                          │
│                                                                 │
│  ROBLOX (3D World):                                             │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │                                                          │  │
│  │   Y (Up/Down - Altura)                                   │  │
│  │   ↑                                                      │  │
│  │   │                                                      │  │
│  │   │    ┌───┬───┬───┐                                    │  │
│  │   │    │   │   │   │                                    │  │
│  │   │    ├───┼───┼───┤                                    │  │
│  │   │    │   │ P │   │  P = (4096, 28, 4096)              │  │
│  │   │    ├───┼───┼───┤                                    │  │
│  │   │    │   │   │   │                                    │  │
│  │   │    └───┴───┴───┘                                    │  │
│  │   │   /                                                  │  │
│  │   │  /                                                   │  │
│  │   │ /                                                    │  │
│  │   └────────────────────→ X (East/West)                  │  │
│  │  /                                                       │  │
│  │ /                                                        │  │
│  │/                                                         │  │
│  └───────────────────→ Z (North/South)                      │  │
│                                                                 │
│  FÓRMULA:                                                       │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ X_roblox = x_ot * TILE_SIZE  (4 studs)                  │  │
│  │ Y_roblox = z_ot * TILE_SIZE  (altura)                   │  │
│  │ Z_roblox = y_ot * TILE_SIZE  (profundidade)             │  │
│  └──────────────────────────────────────────────────────────┘  │
│                                                                 │
│  EXEMPLO:                                                       │
│  ┌──────────────────────────────────────────────────────────┐  │
│  │ OT: (1024, 1024, 7)                                      │  │
│  │ Roblox: (4096, 28, 4096)                                 │  │
│  │                                                          │  │
│  │ Cálculo:                                                 │  │
│  │   X = 1024 * 4 = 4096                                    │  │
│  │   Y = 7 * 4 = 28                                         │  │
│  │   Z = 1024 * 4 = 4096                                    │  │
│  └──────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────┘
```
